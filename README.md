# Boo’s Haunted Castle Challenge

Самостоятельная браузерная игра Peakway English Studio для 1–3 классов. Три миссии в любом порядке, 15 шоколадных медалек, озвучка, подсказки и наградная PNG-карточка. Соседние проекты не изменяются.

## Запуск

Нужен Node.js 22 или новее. В папке проекта:

```sh
npm run dev
```

Откройте http://127.0.0.1:4175. Установка зависимостей для самой игры не нужна. Не открывайте index.html через file://: ES-модули требуют HTTP-сервер.

```sh
npm test
npm run build
```

Сборка находится в `dist/`. Все ссылки относительные: игру можно размещать в подпапке сайта. Проверка сборки локально: `node scripts/serve.mjs --dist` (предварительно остановите dev-сервер).

## GitHub Pages

1. Загрузите содержимое **этой папки** в отдельный GitHub-репозиторий с основной веткой `main`.
2. В Settings → Pages → Build and deployment выберите **GitHub Actions**.
3. После push в `main` workflow `.github/workflows/pages.yml` проверит логику, соберёт игру и опубликует `dist/`.
4. Ссылка появится в успешном запуске workflow. Для ручного размещения можно использовать содержимое `dist/` на любом статическом хостинге.

Публикация в GitHub из этой рабочей папки не выполнялась: целевой репозиторий не указан.

## Замена изображений

Все изображения находятся в `public/assets/`. Подключены 13 присланных PNG: три фона, котёл, листы персонажей, дверей и ингредиентов, меню и пять поездов. Оригиналы сохранены без изменения пикселей. Объекты из общих листов отображаются отдельно через SVG viewBox и clipPath в `src/sprites.js`; двери перемешиваются вместе с рисунками, вагончики остаются отдельными интерактивными буквами. Из меню используются иллюстрации трёх миссий; названия, кнопки, счётчики и отметки завершения создаются программно. Фон станции также используется на стартовом экране.

Для элементов, которых нет среди присланных отдельных изображений (Boo в шляпе, медалька, сундук, локомотив и награда), сохранены SVG-заглушки. Положите рядом PNG **с тем же базовым именем**: например, `boo.png` заменит `boo.svg`. Для замены листа используйте то же имя и размеры либо обновите прямоугольники в `src/sprites.js`. После замены пересоберите проект и обновите страницу. Персонажи и предметы должны иметь прозрачный фон.

Синие пауки и красные звёзды для неверных вариантов используют присланную графику с CSS-изменением цвета. Пиксели исходных файлов не меняются. Насыщенные фоны дополнены светлыми подложками для читаемости заданий и кнопок. В портретной ориентации декоративный фон заполняет экран; все игровые объекты масштабируются отдельно с сохранением пропорций.

Основные файлы:

| --- | --- |

Фоны: 1920×1080; карточки миссий: 600×320; наградной фон: 1000×720; предметы: квадратные. Буквы, надписи, счётчики и кнопки остаются HTML-элементами. Надписи наградной карточки наносятся программно при создании PNG.

Готовая наградная карточка кэшируется, чтобы её можно было повторно скачать без изменений. Если после замены иллюстраций нужно обновить уже созданную карточку на тестовом устройстве, удалите **только** ключ `peakway-boo-haunted-v2-card-png` в localStorage; номер и прогресс останутся прежними.

## Озвучка

Используется доступный английский голос Web Speech API. Кнопка LISTEN повторяет текст, переключатель звука останавливает текущую речь. Автовоспроизведения до взаимодействия нет. Голос и наличие английской озвучки зависят от браузера и установленных системных голосов. Все задания доступны текстом; отсутствие речевого API не блокирует игру.

Для MP3 заполните объект `recordings` в `src/audio.js`: ключ — точный произносимый текст, значение — относительный URL MP3. Игровая логика не меняется.

## Прогресс и управление

- Ключ сохранения: `peakway-boo-haunted-v2`, отдельный от дошкольной игры.
- Каждая пара «миссия:раунд» даёт только одну медальку. Повторное прохождение не увеличивает счёт выше 15.
- Пройденные раунды сохраняются сразу после правильного ответа; незавершённый рецепт или слово можно собрать заново после перезагрузки.
- Номер `B2-XXXXXX` создаётся после 15-й медальки и сохраняется. Глобальная уникальность без сервера не гарантируется.
- Если localStorage недоступен, игра продолжает работать в текущей вкладке и показывает уведомление. Закрытие такой вкладки сбросит прогресс.
- В лаборатории можно перетаскивать предметы мышью/пальцем или нажать предмет, затем котёл. В поезде нажимайте буквы, исправляйте кнопкой UNDO и подтверждайте CHECK WORD.
- Управление доступно с клавиатуры через Tab и Enter/Space. HINT включается после двух ошибок. У длинных слов повторное нажатие показывает до трёх первых букв.
- Масштабирование от холста 1920×1080; портретная компоновка использует холст шириной 780 с перестановкой элементов. `100dvh`, visualViewport и уменьшение анимации поддерживаются.

## Проверки

```sh
npm ci
npm test
npm run test:browser
node tests/artwork.mjs
```

Браузерный тест использует установленный Microsoft Edge и Playwright. На другой системе установите браузер через `npx playwright install chromium` и уберите `channel: 'msedge'` в `tests/browser.mjs`.

Проверяются полные прохождения мышью и касаниями, оба способа добавления ингредиентов, ошибки и подсказки, уникальные медальки, перезагрузка, повторная награда, экспорт PNG и границы элементов на 1920×1080, 1366×768, 1024×768, 768×1024, 390×844. Скриншоты и скачанные PNG записываются в `test-results/`. Проверка озвучки проверяет вызовы API; качество реального голоса нужно прослушать на целевом устройстве.

## Файлы

`src/core.js` — задания и начисление; `src/app.js` — сцены и управление; `src/styles.css` и `src/artwork.css` — адаптивность и оформление; `src/assets.js` и `src/sprites.js` — заменяемая графика; `src/audio.js` — речь/MP3; `src/reward.js` — PNG; `scripts/` — сервер, сборка и генератор SVG.
